## Context

**The category.** Kim's charter for SaaS product utilities, verbatim: *"simple customizable strategy/interface and adapter patterns that allow us to keep UI implementations simple, while the CRUD pathways are highly flexible and customizable, and support concepts like streaming and sockets natively."* The 2026-08-15 research brief ([`../briefs/saas-utilities.brief.md`](../briefs/saas-utilities.brief.md)) surveyed seven canon patterns against the repo: the read pathway (P3), the mutation pathway (P4) and cursor pagination (P5) are MISSING as general seams; the streaming legs (P2) exist in three layers (`site/lib/ndjson-lines.ts`, a2ui `AgentProvider` internals, a2a `A2aChannel`) with none exported; the gateway-facing client contract (P7) is ruled server-side only (a2ui-live-agent SPEC-R16–R19). Three issues carried the findings: #955 (P7), #956 (P3/P4/P5 + the package fork), #957 (P2).

**The house grammar already exists — agent-specific.** `AgentTransport.turn(input): AsyncIterable<string>` + `AgentProvider`'s additively-widened optional capabilities (`effort?` → `onEvent?` → `tools?`, each landing with older adapters byte-unchanged) is a proven strategy seam (ADR-0137). It is agent-turn-shaped by construction; nothing generalizes it to CRUD/query data. The brief's §0 verdict — *pure zero-dep core + interface seam + injected adapters + optional-capability widening + AsyncIterable for anything streamed* — is the grammar to extend, not to invent twice.

**The fork, and its history.** The brief's §3 fork 1 asked: mint `@agent-ui/data` (a zero-dep sibling off `components`, the ADR-0115/0119 precedent) or grow a `data/` layer inside `components`? On 2026-08-15 an AskUserQuestion round ruled *fold into existing packages — no new package* (recorded on #956). On **2026-08-16**, in the clear-the-boards run, Kim re-ruled with the full placement picture in view (#954–#959 together): **mint `@agent-ui/data`**, #957 folds into #956, one PRD/SPEC covers all three, and the mint rides a proposed ADR (this record). The 2026-08-15 comment is superseded by the 2026-08-16 comment on the same issue; this ADR records the later, authoritative ruling and the reasons the alternatives lose.

**The constraints that make the shape inevitable.** (1) The zero-dependency law (CLAUDE.md; ADR-0107's "runtime dependency in costume") forbids TanStack/SWR/RxJS/ky adoption — every pattern must be native `fetch`/`ReadableStream`/`EventSource`/`WebSocket`/`AbortSignal`/async-generator mechanics. (2) The layering law: `components` is `reactive ← dom ← traits ← controls`; a data layer is none of those and would ride every consumer's foundation budget (ADR-0040) — the exact argument ADR-0115 made for the router. (3) Catalog invisibility: `a2ui` must never reach a data-access primitive by import — agent-driven data access is a trust surface wanting its own record. (4) One reactivity kernel: results must surface as `components/src/reactive/` signals, never a second reactive system. (5) Persistence has a ruled home elsewhere: #959 puts `StorageAdapter` in `@agent-ui/shared` (Kim's 2026-08-16 seam-home ruling; #959's own layer-contract ADR is likewise still `proposed` — the two records are concurrently unratified and independent), so this package must not mint a second store interface.

## Decision

**We will admit `@agent-ui/data` as a new zero-dep sibling package off `components` — a headless core `.` carrying the `DataSource` seam + signal-backed `resource`/`mutation`/`paginated` + the `DataError` envelope + an instance-scoped structural-sharing store; a `./gateway` subpath carrying the consumer-side client contract; a `./stream` subpath carrying ONE `Streamed<T>` contract with `fromFetchStream`/`fromEventSource`/`fromWebSocket` adapters — catalog-invisible by construction, `AgentTransport` untouched, persistence deferred to #959's `shared` seam.** Owning docs: the PRD (why/what, PRD-G1…G8) and the SPEC (behavior, SPEC-R1…R14) authored with this record. Six clauses:

1. **Package + DAG** *(PRD-G7; SPEC-R1)*: NEW `packages/agent-ui/data/` → `@agent-ui/data`, `dependencies` exactly `{@agent-ui/components, @agent-ui/shared}`; `shared ← components ← {router, code, data}`; `components`/`a2ui`/`shared`/`router`/`code` never import it (`app` MAY, later); every existing inward layering trip-wire extends its scan by one package name; the package's own `layering.test.ts` bites on a planted upward import.
2. **Three export surfaces, core-only pays nothing** *(PRD-D3/D5; SPEC-R1 AC3)*: `.` (seam, store, resource/mutation/paginated, `DataError`/`normalizeError`, the `Streamed<T>` **type**), `./gateway`, `./stream`; the `.` barrel never imports the subpaths; a tree-shake probe proves a core-only consumer carries no gateway/stream bytes (the ADR-0065/0119 geometry).
3. **The seam and its state machines** *(PRD-G1/G2/G3/G6; SPEC-R2…R5, R7)*: `DataSource<T>` with **every verb optional** (`read · list · create · update · remove · subscribe`) — a missing verb is a runtime `DataError` `missing-capability`, never a type-level obligation, and a new verb never touches an existing source (the `AgentProvider` law generalized); `resource()` = SWR + dedup + prefix invalidation + abort + `live` over `subscribe`, its `pending` signal being what a control wires to ADR-0191's `:state(pending)`; the store is instance-scoped and single-writer with O(1) structural-sharing snapshots (the corpus `put` discipline + the a2ui `setPointer`/`Object.is` mechanism, re-implemented minimally — the DAG forbids importing a2ui's); a module-level default store exists as a documented soft global (the ADR-0115 `defaultRouter` posture); `mutation()` declares `invalidate`/`optimistic` effects with per-run, per-key rollback.
4. **The gateway client** *(PRD-G5; SPEC-R6, R8–R11)*: onion middleware `(req, next) => Promise<Response>` around an injected `fetch`; `withToken` with single-flight 401 refresh and a token that never enters package state; ONE `DataError` envelope `{ kind, status?, code?, retryable, cause }` so UI is driven from `kind`/`retryable` alone; `withRetry` = exponential + full jitter, retryable-and-idempotent only by default, `Retry-After`-honoring, abort-interruptible, attempt-capped; and the **pass-through law**: no built-in middleware reads/tees/buffers a `Response.body` — retry decides from status/headers; a planted body read reds the gate. This is the CLIENT half of the posture SPEC-R16–R19 rules on the server; keys stay server-side, nothing here changes that.
5. **ONE streaming contract** *(PRD-G4; SPEC-R12–R13; GH #957 folded)*: `Streamed<T> = AsyncIterable<T>` (the `AgentTransport.turn()` precedent, cited); a `pushToPull` bridge with a **declared** backpressure policy (`buffer` default with a high-water cue; `drop-oldest`/`drop-newest` opt-in) and exact-once teardown on `return()`/abort; `fromFetchStream` (NDJSON/SSE/lines, POST- and header-capable) **hoisting** `readNdjsonLines` out of `site/lib` (the site keeps a one-line re-export — one implementation body in the repo); `fromEventSource` (GET-only, the no-custom-headers auth constraint stated in its doc, platform `Last-Event-ID`); `fromWebSocket` (heartbeat, opt-in backoff reconnect, `bufferedAmount` backpressure, close `1000` on `return()` — the `A2aChannel` drain-close precedent, a2a untouched). Injected constructors (`fetch?`/`EventSource?`/`WebSocket?`) for jsdom — the shapes are SPEC-R13's.
6. **Pillars + teaching** *(PRD-G7/G8; SPEC-R14)*: headless gate for `core/**` + `gateway/**`; size line-item (SPEC-R14 budgets, re-measured at build and recorded honestly here if they move); CLAUDE.md Layout + DAG rows; a site doc page; M2 dogfood = one `site/` page migrated onto `resource()`/`fromFetchStream()`.

**Explicit non-goals (fenced in PRD §4 / SPEC §4, cited not restated):** no UI controls or CSS/tokens · no a2ui coupling and no `AgentTransport` retrofit · no server code · no persistence adapter / offline / local-first (that is #959's `shared` seam; hydration is a v2 convergence) · no third-party runtime code · no normalized entity graph or query language.

## Consequences

- **The fleet gains a data layer without becoming a framework** — the component tier bundles none of it; consumers opt in per app, per subpath. Cost: a **ninth** workspace package to version, document, budget and trip-wire (`shared, components, a2ui, a2a, icons, app, router, code` + `data`), and every existing inward layering test grows one scan target.
- **The seam is deliberately thin and verb-optional** — which means capability absence is a *runtime* `DataError`, not a compile error; accepted so that a source declares only what it has and adding a verb never churns the ecosystem. Consumers wanting compile-time guarantees narrow the type at their own boundary.
- **A default store is a soft global** (mitigated: instance-scoped `createStore()` is the primary path; tests use explicit stores; flagged honestly, exactly as ADR-0115's `defaultRouter`).
- **The re-implemented structural-sharing store duplicates a *mechanism* a2ui already has** — by DAG necessity (`data` cannot import `a2ui`). Accepted, minimal, cited; if a third copy ever appears, the mechanism moves down to `components/reactive` or `shared` by its own record.
- **`readNdjsonLines` moves** — `site/lib/ndjson-lines.ts` becomes a re-export; its test suite runs against the hoisted body. Existing site importers are byte-unchanged.
- **The 2026-08-15 "fold, no package" ruling on #956 is superseded** by the 2026-08-16 ruling this record carries; the issue's comment stream shows both, dated — this ADR is where a future reader finds *why* the later one stands (Context).
- **Persistence stays split by design**: `StorageAdapter` in `shared` (#959), cache hydration onto it a named v2 item here — two waves, one interface, no fork.
- **Stale → re-verify at the build wave:** CLAUDE.md Layout/DAG rows · `measure-size.mjs` budgets (SPEC-R14; amend this row with measured numbers, never silently raise) · site nav/toc gates · every inward `layering.test.ts` · this record's Ratified-by field.
  - **Build-wave measurement (2026-08-16, `npm run size`, min+brotli, gz alongside):** `.` **2822 B br** (3106 B gz, 8091 B min) vs the 6 kB budget · `./gateway` **1729 B br** (1928 B gz, 4198 B min) vs 3 kB · `./stream` **2042 B br** (2281 B gz, 5541 B min) vs 4 kB — all within, no re-base. The `.` figure is ABSOLUTE (not marginal-over-foundation): the barrel pulls only the reactive kernel from `@agent-ui/components`, which Rolldown tree-shakes to the kernel — the tree-shake probe asserts zero `./gateway`/`./stream` modules and no `HTMLElement`/`customElements` bytes in it (SPEC-R1 AC3, gated). CLAUDE.md rows, the four inward trip-wires, and `site/data-doc.html` (+ manifest/sitemap/llms rows) landed the same wave.

## Alternatives considered

- **Grow a `data/` layer inside `@agent-ui/components` (brief fork 1, the 2026-08-15 lean).** Rejected: a data layer is none of `reactive ← dom ← traits ← controls`; it rides every consumer's foundation budget (ADR-0040) and gives `a2ui` — a `components` consumer — an import path to data access, breaking catalog invisibility by construction. The 2026-08-16 ruling reversed the 2026-08-15 lean on exactly these grounds.
- **Put the seams where each precedent lives (streaming near a2ui's agent seam, storage in `shared`, resource in `app`).** Rejected: it scatters ONE grammar across three packages with three DAG positions, and puts a general streaming contract inside `a2ui`, whose root barrel must carry zero producer bytes (ADR-0137) and which nothing below `app` may import — the general consumer would have no reachable home.
- **Retrofit `AgentTransport` into a `DataSource` specialization (brief fork 2).** Rejected (PRD-D2): churns a shipped, thrice-proven seam for no consumer; the shape is generalized, the instance is cited. A future `agentSource(transport)` adapter in `data` can wrap it if a consumer appears — one-way, `data` importing nothing from `a2ui` (so it would live in `app` or the consumer).
- **A separate `@agent-ui/gateway` package (brief fork 3).** Rejected (PRD-D3): the error envelope IS `resource.error`'s type, so core and gateway share a type home; a subpath gives the same tree-shake isolation without a tenth package.
- **A `./stream`-less core with adapters in `components/traits`.** Rejected: traits are `(host, opts) => cleanup` and die with their host; a stream outlives hosts and is consumed headless.
- **Vendor a query library or an SSE/WebSocket client "as pattern".** Rejected without ceremony: ADR-0107's "runtime dependency in costume" law; every mechanism here is native.
- **Make the store URL/`localStorage`-backed by default (persistence in v1).** Rejected (PRD-D4): #959 owns the `StorageAdapter` seam in `shared`; two store interfaces in one wave is the fork the brief warned against; hydration is a v2 convergence once #959 Slice 1 lands.
- **An A2UI catalog `Resource`/`Stream` type at v1.** Rejected (fenced): agent-driven data access is a trust surface wanting its own record (the ADR-0034 gate posture); the DAG enforces the fence structurally.
