## Context

GH #1841: the Test Chat strip shows "Reasoned 0.0s" and nothing else. Most of the path to the text already exists in the tree, and one part of it is closed on purpose.

- The Anthropic adapter receives `thinking_delta` events and surfaces them through the optional `onEvent` seam as `ProviderEvent{kind:'thinking', text}` (ADR-0146 F1). Thinking only flows when the effort dial is above low; `low` sends no thinking parameters at all.
- `produce()` turns each into a `reasoning` progress event. Under `progressDetail:'full'` the event carries `detail`, an excerpt capped at 200 characters (ADR-0146 F3). By default it carries no text.
- ADR-0146 F3 ruled the UI leg too: raw reasoning renders only behind the opt-in disclosure affordance, collapsed by default. That leg was never built.
- `progressDetail` holds one value, and `'full'` and `'source'` are independent. The admin runner sends `'source'` (ADR-0159 wave B), so it cannot ask for `'full'` as well. Both proxies honor only `'source'` and drop everything else: "`'full'` stays server-owned".
- The A2UI adapter (`site/lib/a2ui-activity.ts`) returns early when the same stage repeats, so even an excerpt that arrived would be discarded.
- The strip's per-entry reveal (`StatusEntry.source` and `sourceLabel`) is a disclosure built on native `details`/`summary` (ADR-0113, ADR-0143): collapsed by default, button semantics, keyboard operation, text set as `textContent`. It is planted when the row is appended, and a later `update` re-stamps the same node but never adds a reveal to a row born without one.

## Decision

1. **The source is the provider's thinking text, not a model-written note.** It rides the path above unchanged: `thinking` delta, `reasoning` progress `detail`. No wire shape changes: `TurnProgress`, `TurnTrace`, the `a2uiMeta` vocabulary and `AgentTransport` stay as they are. A provider that sends summarized, redacted or no thinking simply yields less text; the strip shows what the adapter receives and claims nothing else.
2. **A new request flag, `ProduceOptions.progressReasoning?: boolean`, forwards the same bounded excerpts on its own axis.** `progressDetail:'full'` is untouched (still server-owned, still equivalent to reasoning alone). The proxies read a `progressReasoning` request key and honor exactly the boolean `true`; any other value is dropped, so the default stream carries no thinking text. The admin runner sends it beside `'source'`; a2ui-chat, a2ui-live, the devtools harness and the doc pages never do. This changes ADR-0159 wave B's "stays server-owned" posture for one consumer, the admin developer surface, which already receives raw wire lines under `'source'`. That is the decision for Kim.
3. **The neutral model carries it: `ActivityStep.reasoning?: string`.** Any host with a thinking concept fills it; the control knows nothing of A2UI. The A2UI adapter concatenates the `detail` excerpts onto the Reasoned step, starts a new paragraph when a later round re-enters the step, drops empty and non-string excerpts and whitespace before any text, keeps whitespace between words, and stops growing once the text passes the cap. The text never reaches a label or a summary (ADR-0146 F2: labels come from the closed table), and never joins `raw`.
4. **The display is the existing reveal, not a new control.** `stepEntry` maps `reasoning` to `source` with `sourceLabel: 'Reasoning'`, so the Reasoned row itself expands into a panel: collapsed by default, native summary semantics (no host ARIA and no ElementInternals work needed, the details/summary part is the semantic element), plain text in the reveal's mono block with its existing 12rem scroll bound. `ACTIVITY_REASONING_CAP` is 4,000 characters, enforced by `activityReasoning` with an explicit truncation marker, and adapters stop growing text at the same constant. A step with no usable text carries no `source` key, so its row is byte-identical to today's. While the step runs, the panel grows live under the "Reasoning…" label and its timer; settled, it is the "Reasoned" row with the same panel.
5. **Cost and privacy.** The flag adds no model cost: thinking tokens are billed whenever the effort dial turns thinking on, whatever is displayed, and this change adds no switch for enabling it. The text is raw, sometimes wrong-then-corrected, model-authored text, so it appears only behind a click, in a panel labelled "Reasoning", never in a label. It lives in the page's DOM; this change adds no persistence path for it.
6. **Devtools capture and replay (ADR-0239) are unchanged.** The harness never sends the flag, so its captures carry no excerpts. A capture of a turn that did request them records each excerpt as an ordinary `progress` meta event and replays them in order under ADR-0239's law. Such a capture is larger (one event per thinking delta) and may hold raw reasoning, so it is a sensitive developer file. No key, provider or `produce()` import enters devtools (ADR-0073, ADR-0200).
7. **Tests are keyless.** Scripted turns carry `detail` text on their `reasoning` progress events (a provider stub driving `onEvent`, or a recorded transport's authored `progress`), and every test in this change runs without a key or a paid call.

## Consequences

- With the admin runner's request and an effort above low, the Test Chat's Reasoned row gains a collapsed "Reasoning" panel whenever the provider returns thinking text. With no text, or on any other consumer, the strip is exactly what it was.
- Known limit: the reveal is planted when the row is appended. A reasoning step whose first event carries no usable text (an empty or whitespace-only first delta) is born without a panel and never gains one; it shows today's look. Adding late arming to `StatusEntry.source` is a components change and is deferred.
- The wire carries one progress line per thinking delta while the opt-in is on, and the strip re-stamps the panel text on each, until the cap is passed and the adapter stops emitting. Coalescing excerpts in `produce()` is a follow-up if the chatter matters.
- The panel reuses the reveal's mono block, so reasoning prose shows in a monospace font in v1. A prose-styled block is a status-stream CSS change, deferred.
- Repaired in the same change: the status-stream `sourceLabel` text, the spec's ADR-0146 amendment, the agent-model glossary row, the `a2ui-jsonl-mcp` reference, and pointers from ADR-0146 F3 and ADR-0159. Any other doc that says raw reasoning cannot reach the strip should be read against this record.

## Alternatives considered

- **A model-authored reasoning note, as a new meta arm or the existing `note`.** Rejected: it is model prose presented as reasoning, which is the fabrication ADR-0146 F2 guards against; it spends output tokens on every turn; it churns the byte-pinned prompt stack and its baseline; and `note` is already the user-facing reply.
- **Reasoning on `TurnTrace`.** Rejected: the trace ships only on a leading meta-line with a note or an ask, arrives after the turn so nothing shows live, and is a runtime record other consumers keep, which is a worse home for raw reasoning.
- **A new `ui-reasoning-panel` control.** Rejected: it needs a descriptor, registry entry, tests and a size budget, and a second fold primitive (ADR-0143's one-disclosure law), for a reveal the strip already has. Reconsider only if the panel needs structure the reveal cannot hold, such as markdown or a copy action.
- **Let clients request `progressDetail:'full'`.** Rejected: it cannot be combined with `'source'`, and it opens the gate for every consumer instead of one.
- **Widen `progressDetail` to a list or a `'source+full'` member.** Rejected: it touches both proxies, the runner and every pin of the request shape to name a combination one boolean names.
- **A settle-time "Reasoning" row, the Raw output precedent.** Rejected: it lands detached at the bottom of the strip, shows nothing while the step runs, and is not the Reasoned line expanding.
- **Late-arming reveals in `ui-timeline-item`.** Deferred, not rejected: it closes the known limit above at the cost of a components change.
- **Turning extended thinking on by default.** Out of scope: it costs tokens on every turn, and the effort dial stays the only switch.
