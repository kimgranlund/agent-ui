## Context

**The need (GH #1122).** Debugging chat + A2UI production issues today means hand-driving the agent-admin app or the a2ui-chat page and eyeballing surfaces. There is no agent-drivable way to run a turn and get the raw JSON payload timeline back, no deterministic backend for CI-shaped repro, no first-class way to capture a failing session and replay it, and no browser-truth hook an automated run can assert render success against. Kim's Rulings comment (2026-08-17) resolved the four intake forks, and this record turns them into one ratifiable decision.

**What already exists — cited, never re-drawn.** The turn seam is `AgentTransport.turn(input): AsyncIterable<string>` with the browser-held `Session`/`TurnInput` model (ADR-0137, `packages/agent-ui/a2ui/src/agent/agent-transport.ts` + `session.ts`) — the ONE interface every consumer binds to, proven across the recorded backbone, the dev proxy, and the Worker twin. The live path is the dev-proxy mount `/__a2ui/agent` (`a2ui/tools/agent/dev-proxy-plugin.ts`): key server-side, PAIR-allowlist, validated NDJSON out, `a2uiMeta` meta-lines in-band. The A2A layer ships `A2aChannel` + a loopback pair + an isolation-proven arena (`packages/agent-ui/a2a/`). The agent-admin app ships a debug-export bundle (`site/pages/agent-admin-debug-export.ts`: `DebugBundleManifest` v1, zip of `agent-settings/`, `test-chat/`, `builder-interview/` + `manifest.json`). The chat surface is the shipped `ui-conversation` re-host (`site/pages/a2ui-chat.ts`) and the canvas the a2ui-canvas render path. A harness that re-invented any of these would be the fork this repo's whole seam discipline exists to prevent.

**The constraints that shape the placement.** (1) The zero-dependency law: every default barrel stays dependency-free; Playwright must never become a runtime dependency. (2) The trust boundary (ADR-0073 clause 5): keys live behind the dev-proxy/Worker mount only — a debugging package that imported provider adapters or `produce()` would re-open the boundary ADR-0137 deliberately closed to a site-internal shell. (3) The import DAG: nothing imports upward; `a2ui`'s root barrel carries zero producer bytes; `a2ui` must never gain an import path to a dev harness. (4) Reuse beyond this repo (gen-ui-kit named in the ruling): the headless core must be a real package export, not site-internal code.

## Decision

**We will admit `@agent-ui/devtools` as a new top-tier workspace package — dependencies exactly `{@agent-ui/a2ui, @agent-ui/a2a}`, zero third-party runtime deps — carrying a three-backend transport shelf behind the unchanged `AgentTransport` seam, a `DevtoolsEvent` NDJSON timeline vocabulary, a dev-only `./server` HTTP orchestration seam, a types-only `./playwright` helper, and a `DevtoolsCapture` format that rides the agent-admin debug bundle additively; the harness PAGE itself stays site-internal (`site/pages/devtools-harness.*`), reusing the shipped chat/canvas surfaces.** Owning behavior doc: [`../spec/devtools-harness.spec.md`](../spec/devtools-harness.spec.md) (SPEC-R1…R12). Seven clauses:

1. **Package + DAG position** *(SPEC-R1)*: NEW `packages/agent-ui/devtools/` → `@agent-ui/devtools`, `dependencies` exactly `{@agent-ui/a2ui, @agent-ui/a2a}`. Each edge justified: **a2ui** — the harness's entire subject is A2UI turns; it consumes `AgentTransport`/`Session`/`TurnInput` (types + the pure session reducers) and nothing from `a2ui/tools/**` (the site-shell boundary, ADR-0137). **a2a** — the peer backend is `A2aChannel` + the loopback pair; a2a imports nothing, so the edge is DAG-clean. **components/shared** — NOT declared: devtools imports neither directly (they arrive transitively through a2ui; the harness PAGE, which does compose `ui-*` controls, lives in `site/`, not in this package). **app** — NOT an edge in either direction: the chat-component reuse happens in the site page via `@agent-ui/app` imports the site already makes; `app` and `devtools` are peer top-tier consumers (`shared ← components ← a2ui ← {app, devtools}`, plus `a2a ← devtools`). `a2ui` must never import devtools — trivially enforced by the nothing-imports-upward law, and made mechanical anyway: every existing inward `layering.test.ts` extends its forbidden-list by `@agent-ui/devtools` (so devtools is catalog-invisible the way `router`/`code`/`data` are, by construction — but from ABOVE the catalog, not beside it).
2. **Three export surfaces, core pays nothing** *(SPEC-R1 AC3)*: `.` (transports, backend descriptors, `DevtoolsEvent` + `recordTurn`, `DevtoolsCapture` + parse/serialize — browser-safe, zero I/O at module scope) · `./server` (the Node/Vite harness plugin — dev-only, the `apply: 'serve'` posture) · `./playwright` (the helper). The `.` barrel never imports the subpaths (the ADR-0119/0192 geometry).
3. **Three backends at turn 1, ONE interface** *(SPEC-R2…R5; ruling clause 3)*: all three are `AgentTransport` implementations — `replayTransport`/`scriptTransport` (canned JSON timelines; deterministic: two runs yield byte-identical line sequences; the CI backbone and the fixture source), `proxyTransport` (POSTs the turn to a dev-proxy-shaped mount and yields its NDJSON lines; injected `fetch`; **no key, no provider adapter, no `produce()` import ever enters this package** — the live boundary stays exactly where ADR-0073 put it), and `peerTransport` (frames a `TurnInput` onto an `A2aChannel` peer — the arena's isolation boundary reused as a harness backend). A `listBackends()` descriptor row (`{id, label, available()}`) feeds both the page switcher and the seam's `/status`. Swapping backends is a one-construction-site edit — the SPEC-R1 AC2 law of the a2ui pages, inherited verbatim.
4. **The orchestration seam and its wire contract** *(SPEC-R6…R7; ruling clause 1)*: `devtoolsHarnessPlugin()` (`./server`) mounts `/__devtools` under `vite dev` only — `GET /status` (backend availability rows) · `POST /turn` (`{backend, input: TurnInput, …}` → a streamed `application/x-ndjson` body) · `GET/POST /captures` + `GET /captures/:id`. The NDJSON wire shape is the `DevtoolsEvent` union, one JSON object per line, envelope `{seq, at, kind}` with kinds `turn-start · line · meta · client · render · turn-end · error`: `line` carries each raw emitted A2UI JSONL line verbatim; `meta` carries parsed `a2uiMeta` lines routed distinctly; `render` carries per-surface browser-truth verdicts (posted by the page; a headless seam run marks them absent, never fabricated); `turn-end` carries `{status, lines, ms}`. The seam serializes exactly `recordTurn`'s timeline — one vocabulary, no second shape between page, seam, and capture.
5. **The harness page — site-internal, reusing the shipped surfaces** *(SPEC-R8…R9)*: `site/pages/devtools-harness.{html,ts}` composes the SAME `ui-conversation` chat the a2ui-chat/agent-admin surfaces ship, a backend switcher over clause 3's descriptors, a live raw-payload timeline pane rendering `DevtoolsEvent` rows, an A2UI canvas render-confirm view (per-surface rendered/failed verdicts, re-emitted as `render` events — a failure is a visible verdict row, never a blank canvas), and capture export/import. The page is the ADR-0137 placement law applied again: portable core in the package, the composed browser surface site-internal.
6. **The Playwright helper — types-only** *(SPEC-R11)*: `./playwright` exports pure functions over a **consumer-supplied** `Page` (`openHarness · selectBackend · postTurn · waitForTurnEnd · readTimeline · expectRendered · exportCapture`). Playwright appears only as `import type` (erased by `verbatimModuleSyntax`) + a devDependency for the repo's own smoke spec — never a runtime or production dependency, so the zero-dep law holds without a ruled exception.
7. **The capture format + debug-export round-trip** *(SPEC-R10; ruling clause 4)*: `DevtoolsCapture = {kind: 'agent-ui-devtools-capture', version: 1, createdAt, backend, session, timeline: DevtoolsEvent[]}`. The agent-admin debug bundle gains an ADDITIVE optional `captures/<id>.json` family and a `files.captures?: string[]` manifest field; `DEBUG_BUNDLE_VERSION` stays 1 (the field is optional and every pre-existing reader parses v1 bundles byte-unchanged — the manifest's own bump rule says bump only when a consumer MUST know; an ignorable addition is not that). Round-trip law: a capture exported from either surface replays through `replayTransport` to a byte-identical `line` sequence.

**Explicit non-goals (fenced in SPEC §4):** NOT a test runner or assertion framework (the Playwright helper wraps the page; scheduling, retries, and reporting belong to the consumer's runner) · NOT CI infrastructure (no workflows, no shards; the repo's existing gates adopt the smoke spec, nothing more) · NO key handling, provider adapters, or `produce()` in this package (the trust boundary stays at `/__a2ui/agent`) · NO new chat/canvas UI components (reuse only) · NO production mount (`./server` is `apply: 'serve'`; a Worker twin is a future record if ever earned) · NO a2ui protocol or seam changes (`AgentTransport` byte-unchanged).

**Build slices, ordered (each one dispatchable; the decomposition's n-ids):** S1 package skeleton + layering trip-wires (n1) → S2 the three transports + backend descriptors (n2a–n2d) → S3 the timeline vocabulary + the `./server` seam (n3a–n3b) → S4 the harness page (n4) → S5 the Playwright helper + smoke spec (n5) → S6 capture format + debug-export round-trip (n6) → gates/teaching rows (n8, folds into S6's PR or ships last).

## Consequences

- **The fleet gains an agent-drivable debug surface without touching the trust boundary** — an external agent can POST a turn and read the whole payload timeline headlessly, and a browser-truth run is one helper away. Cost: a **tenth** workspace package to version, document, and trip-wire, and every inward layering test grows one scan target.
- **Two headless mechanisms is a real surface-area cost, accepted by ruling** — the seam (fast, DOM-less, marks render truth absent) and the Playwright wrap (slow, real engine, owns render truth) answer different questions; the ruling took both deliberately. The `render` event's absent-when-headless rule is what keeps the seam honest instead of fabricating browser truth.
- **The live backend is HTTP-coupled to the dev-proxy's request/response shape** — a proxy body change can break `proxyTransport` without a compile error. Accepted: the alternative (importing the proxy's internals) re-opens the ADR-0137 shell boundary; the SPEC pins the body fields the transport relies on, and the round-trip suite catches drift.
- **The debug bundle's additive `captures` family creates a second writer of the bundle shape** (harness export alongside agent-admin export). Mitigated: one format module owns serialization; the additive-proof test asserts every pre-existing bundle test passes unchanged.
- **Replay determinism fences the capture format** — anything nondeterministic (timestamps in `line` events, unordered maps) is a format defect by definition; `seq` ordering is the contract.
- **Stale → re-verify at the build wave:** CLAUDE.md Layout/DAG rows · the inward trip-wire list · site nav/manifest gates · this record's Ratified-by field · the SPEC's v0.1 rows against what actually built.

## Alternatives considered

- **Grow the harness inside `site/` only (no package).** Rejected: the ruling names reuse beyond this repo (gen-ui-kit); site-internal code has no export surface, and the transports/timeline/capture core is exactly the portable half the ADR-0137 placement law says belongs in a package.
- **Fold into `@agent-ui/a2ui` (a `./devtools` subpath).** Rejected: it would drag a2a into a2ui's dependency set (the peer backend), put a dev harness inside the catalog package whose root barrel must stay producer-free, and make the a2ui-must-never-import-it rule self-referential instead of structural.
- **Fold into `@agent-ui/app`.** Rejected: `app` is the composition tier consumers ship to PRODUCTION; a debug harness in its dependency graph taxes every app consumer with dev tooling, and `app` does not (and must not) depend on `a2a`.
- **A components-sibling position (`shared ← components ← devtools`, the router/code/data geometry).** Rejected: devtools's subject is the a2ui turn seam and the a2a channel — below-a2ui placement would forbid both imports and force re-declaring the seam types (the exact duplication ADR-0192 refused for `AgentTransport`).
- **Run the live model inside the harness seam (import `produce()` + adapters into `./server`).** Rejected without ceremony: ADR-0073 clause 5 — the key boundary stays at `/__a2ui/agent`; the harness reaches it over HTTP like every other client, so a key can never leak through a debug tool.
- **Adopt Playwright as a real dependency of `./playwright`.** Rejected: a types-only helper over a consumer-supplied `Page` delivers the same API with zero runtime deps; the ADR-0139 ruled-exception machinery is not needed and therefore not spent.
- **A new capture format disjoint from the debug bundle.** Rejected by ruling clause 4: one format, captures round-trip between the app and the harness; a disjoint format is the two-writers fork with none of the benefit.
- **SSE or WebSocket for the seam instead of NDJSON.** Rejected: the dev-proxy and the whole a2ui wire already speak NDJSON lines; `POST + application/x-ndjson` reuses the exact reader idiom (`readNdjsonLines`, now `@agent-ui/data/stream`'s hoisted body) and stays curl-able for an agent driver.
