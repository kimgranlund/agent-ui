## Goal
Agent-admin seed content (15 presets, the Builder preset, library packs) lives as typed files with frontmatter, indexed by a generated registry, so the Builder, a CLI, Test Chat and the settings pane all read one source. First of four (T-0160 files, T-0161 overlays, T-0162 schema forms, T-0163 compiler). Kim 2026-10-14: straight to tickets, no ADR.

## Intent
- Do:
  - Pick one content home (proposal: `packages/agent-ui/app/src/agent-content/` or beside the a2ui mini-skills, whichever keeps the package DAG; site-internal stays site-internal) with this shape:
    - `personas/<id>/agent.md`: frontmatter (id, version, label, category, model, temperature, surfaces, catalog, fragments, skills/workflows/resources/tools as `id@version` refs); body = foundation; surfaceStyle as a named section.
    - `skills/<id>/SKILL.md` (Agent Skills format: `name`, `description` plus id, version, kind, availability), same for workflows, resources, tools.
    - `packs/<id>/pack.json`: refs only, no copies.
    - `AGENTS.md` in the content root: schema summary, how to add a persona or skill, the validate command, naming rules (authoring context, never loaded at runtime).
  - A schema per kind (TS types + validator) and `scripts/generate-agent-content.mjs` that emits `registry.gen.ts` (id, kind, version, digest, path, parsed frontmatter, body), drift-gated like the other `*.gen.ts` (`--check` in `check:scripts`, a freshness test).
  - Extract every preset and pack from `site/pages/agent-admin-presets.ts` and `agent-admin-libraries.ts` into files; those modules become thin readers of the registry. Byte-identical assembled prompts for every preset (prove with a before/after digest test over all 16), so no `seedVersion` bump is needed.
  - Fold the existing mini-skill and GenUI pack `.md` reads into the same registry.
  - Agent manifests (`site/lib/agent-manifest/*.manifest.json`) read digests from the registry instead of hand refresh, or are generated by the same script.
  - Move the `seedVersion` rationale from trailing comments into frontmatter (`changelog:` list).
- Non-goals: overlays and merge (T-0161), form generation (T-0162), compiler (T-0163), new presets, content rewrites.
- Done when: `npm run check` exit 0; generator `--check` exit 0 and fails on a hand-edited registry (negative control); assembled-prompt digests for all presets equal before and after; `site/pages/agent-admin-*.test.ts`, `site/lib/agent-manifest`, `site/lib/capability-registry.test.ts`, `packages/agent-ui/app/src/controls/agent-admin` tests exit 0; `npm run e2e:admin` exit 0.

## Context
- Survey 2026-10-14: seeds are TS constants (presets.ts 1,117 lines; libraries.ts hand arrays); only mini-skill and GenUI packs are `.md` via `import.meta.glob`. Persistence and stores: ADR-0227 grammar, `StorageAdapter`, `DataSource`. Layering rules: each package's `layering.test.ts`.
- Start after T-0159 lands (it edits the same preset text).

## Constraints
- Zero runtime dependencies (no YAML library: parse a small frontmatter subset, or author frontmatter as JSON). Package DAG unchanged. No em dashes.
