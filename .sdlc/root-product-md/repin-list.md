# T-0152 re-pin list: the test files the product / md root turned red

Source: the unit suite and the six browser shards, each run once (foreground, through `gate_lock.py`) on `feat/root-product-md` at `75e31ce5`, rebased onto origin/main `305540bd` (#1961 to #1967; the generated files and goldens taken from main and regenerated by script). Em dashes in quoted test titles are written as hyphens. 232 failing tests in 75 files. Chromium and WebKit each count once under *engines*; the visual shard runs one engine. Grouped by the census lane partition (`laneOf` in `scripts/foundations-census.mjs`) so each group can run as its own file-disjoint lane. `result-card` rides a06 as in T-0120; `unlaned` is outside the partition. Main was not re-run as a baseline: every message below moves by the root delta (n 5 / 6 / 7 to 6 / 8 / 10), and none reads as unrelated.

Cause: ADR-0245 Amendment 8. The root moved from product / sm (n 5 / 6 / 7, heights 20 / 24 / 28) to product / md (n 6 / 8 / 10, heights 24 / 32 / 40; m 8 at md, so card 24 / 16 / 24 and layout 32 / 24 / 32). `scale.mjs` did not change. A lane re-pins with scale.mjs `resolve()` at the root register, now `resolve('product', 'md', size)`, never a literal. Most red files read `resolve('product', 'sm', …)` as "the root"; that call is still correct for an explicit product / sm region and wrong for the root. The A2UI canvas stays widget / md (n 5 / 6 / 7), so a test that sets that register does not move. `derive.out.md` section 21 has every before and after.

Columns: *pinned* is the value the test asserts and *measured* is what renders now (the vitest message reads "expected <measured> to be <pinned>"); *suite* is the shard.

Kinds. A *value pin* takes the derived value (a tolerance on a root-derived offset counts as one, and so does a "got X, want Y" row of `control-rule.browser.test.ts`, whose titles name the n 5 / 6 / 7 root). A *golden* is re-minted after eye review. A *law check* is an inequality or a lint finding the larger root newly breaks or newly meets: look before changing the test.

Fixed in this change and green in this run: `shared/src/tokens/foundations.browser.test.ts` (the root register now product / md), `site/gallery.browser.test.ts` (the gallery's default scale is md), the `glyph-box at n 5` negative control of `site/pages/dogfood-render.browser.test.ts` (the plant sets `data-scale="sm"` to reach n 5), and the two regen artifacts (`site/lib/__fixtures__/theme-provider-built.css`, `sandbox-frame/dogfood/dogfood-assets.ts`). The packages-rest shard is green. Left out: one `site/lib/controls-coverage.test.ts` red caused by a stray, git-ignored `controls/__screenshots__/` folder of failure screenshots from the previous run; deleted, the test is green. Also green: `foundations.test.ts`, `npm run check`, the census gate and `foundations-probe.mjs --strict` (48 rows at product/md, 0 mismatch).
