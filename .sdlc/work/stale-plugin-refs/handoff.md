## Goal
Repair the live skills, agents and docs that still name agents or skills from the plugins PR #1791 disabled, so none of them sends a reader to a seat that does not load here. Tracks GH #1798.

## Context
PR #1791 set the seven nonoun-plugins (llm, harness, docs, teamwork, frontend, agent-protocols, design) to false in `.claude/settings.json`. These prefixes still appear: `teamwork:` (code-checker, docs-writer, planner, builder, build-leader, wiring-checker, fleet-marshal), `frontend:` (component-checker, layout-checker, flow-checker), `docs:` (doc-checker, doc-writing-rules), `design:` (token-builder). Find them with `git grep -n -E 'teamwork:|frontend:|docs:(doc|scribe|writing)|design:' -- .claude ':(exclude).claude/docs/adr' ':(exclude).claude/docs/reports' ':(exclude).claude/docs/archive'`. At plan time about 60 files match, but most are HISTORICAL records (decompositions, tickets, LLDs, research, the overhaul plan, audit reports, evals fixtures) and must not be rewritten.

In scope (live routing text a reader acts on): `.claude/agents/*.md`, `.claude/skills/**/SKILL.md` and their `intent.md`, `.claude/docs/process.md`, `.claude/docs/rubrics/*.md`, `.claude/docs/references/*.md`. Out of scope: ADRs, dated reports, archive, tickets, decompositions, LLDs/SPECs/PRDs prose that merely cites history, `evals/*.json` and `evals/audit-report.md` fixtures, `.claude/overhaul-plan-*.md`. Read `.claude/skills/doc-standards/SKILL.md` before touching doc prose and `.claude/skills/seat-map/SKILL.md` first: its seat table is the main site.

What loads here: repo-local agents `a2ui-build-agent`, `a2ui-payload-authoring-agent`, `a2ui-review-agent`, `component-build-agent`, `example-authoring-agent`, `repo-orchestrator-agent` (see `.claude/agents/`), the sdlc-lite roles (planner, builder, verifier, plan-reviewer, filer, scout, researcher, architect, archaeologist, solo) and its conductor, plus built-in `Explore`, `Plan`, `general-purpose`. There is NO repo-local checker for ui-* controls, layout, flow, code, docs or wiring.
