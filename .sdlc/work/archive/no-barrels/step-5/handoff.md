## Task goal
Design how agent-ui stops relying on barrels (the `src/controls/index.ts` family barrel and the `component-styles.css` CSS barrel, plus the other package barrels where the same problem applies) so that consumers load only the controls they use, tree-shaking works, and adding a control no longer means hand-editing shared lists. Design only: no code, no edits.

  - `interface ControlLoader { missing(tags: Iterable<string>): string[]; ensure(tags: Iterable<string>): Promise<void> }`. `missing` is synchronous (tags with `customElements.get(tag) === undefined`), so a renderer keeps a sync fast path with no microtask.
  - `interface ControlLoaderOptions { css?: 'host' | ((css: string, record: ControlRecord) => string | URL) }`; default resolver `new URL(css, import.meta.url)` (registry paths are relative to `src/controls/`, where `loader.ts` lives). `'host'` never touches `document.head`.
  - `createControlLoader(records: Readonly<Record<string, ControlRecord>>, options?: ControlLoaderOptions): ControlLoader`, `ensureControls(tags, options?)` over `CONTROLS`, and `class ControlLoadError extends Error { readonly tags: readonly string[] }`.
  - `ensure`: unknown tags reject with `ControlLoadError` naming them; nothing missing resolves at once and links nothing; otherwise `await record.load()` for each missing tag (no recursion over `uses`: a module's imports carry its JS dependencies and its sheet's prologue carries its CSS, so text-field's lazy calendar and color-picker stay lazy); then, outside `'host'` mode, append `<link rel="stylesheet" data-ui-control="{tag}">` only for tags this call defined, deduped by resolved href across calls, and await each link's `load` or `error` (`error` warns naming the sheet and still resolves). jsdom never fires `load` on a `<link>` (architect-L1.md Constraints), which is why built-in catalogs use `'host'` (step 6).

- Renderer deferral, per surface S whose entry has `controls`: on `updateComponents`, tags = the `factoriesOf(entry.factories[node.component]).map(f => f.tag)` union over the message's components (factories create only their own tag: planner grep of `createElement('ui-`); when S has no queue and `missing(tags)` is empty, apply synchronously exactly as today. Otherwise queue the message, and every later message for S (`updateComponents`, `updateDataModel`, `deleteSurface`, `finalize(S)`) while S's queue is non-empty; with no ensure in flight, call `ensure(missing)`; on resolve, drain S's queue in order, re-checking `missing` per queued message; on reject, emit `CONTROL_LOAD` with `surfaceId` once and drain anyway, rendering any node whose tag is still undefined through the existing `a2ui-placeholder` path instead of creating an undefined element. `deleteSurface` while pending tears down and drops S's queue; `dispose()` drops every queue, and late resolutions are no-ops. `createSurface` and other surfaces are never delayed.
