## Approach

The guidance is a prompt-time asset, not a render contract, and the system's constraints decide its home. Every browser consumer of the renderer bundles `catalog/default/catalog.json` (the app barrel drags the whole default catalog, `scripts/measure-size.mjs:553-560`), and the app marginal bundle budget sits at exactly its cap with the ADR-0197 cl.5 exception already invoked a "FOURTH and FINAL" time (`measure-size.mjs:686-700`). Prose that only the model ever reads cannot ride `catalog.json` without redding a gate the repo has declared closed. The validator (`catalog/conformance.ts`) and renderer never need selection guidance; only `buildSystemPrompt` (Node-only, already reading `prompts/*.md` via `node:fs`) and Node-side evals do. The repo already keeps per-type catalog POLICY beside the agent rather than in the catalog: `agent/feed-catalog.ts` (`FEED_SURFACE_TYPES`, ADR-0097, which explicitly rejected a policy view inside the catalog). The design follows that mechanism.

One sidecar per catalog, `selection.json`, beside its `catalog.json`: `catalog/default/selection.json` (80 types), `catalog/a2ui-basic/selection.json` (14 types), `catalog/personas/<id>/selection.json` (fragment types, personaId-pinned). Each entry is `{ intents: string[1..3], notFor: [{ type, why }][0..4] }`. No `confusableWith` field: a confusable pair IS a `notFor` edge, and reciprocity inside a first-party catalog makes every pair closed with a `why` per direction. A new Node-only module `agent/selection-guidance.ts` loads the sidecars at module load (paths from `process.cwd()`, the TKT-0044 rule), validates shape and caps with typed errors, resolves a `Catalog` to its guidance (`agent-ui` to `default/`, `a2ui-basic` to itself, derived `<base>--<persona>` ids split on the first `--` and union base + persona), throws on an unresolvable `notFor` target (the `calibrationExampleBullet` precedent), and renders one clause. `catalogInventory` appends the clause after `(props: ...)` on the same line so `prompt-drift.test.ts`'s `^- (.+?) \(` id regex survives: `- Badge (props: ...) · use: short status label; count · not for: Progress (a quantity that changes), Toast (an ephemeral outcome)`. A catalog with no sidecar composes today's line byte-identically (the planted-ghost tests keep passing).

Coverage is a gate, not a list: `catalog/selection-guidance.test.ts` asserts a bijection between each shipped catalog's type set and its sidecar (a new emittable type without guidance reds, as does an orphan entry), per-entry caps, no self or duplicate edges, reciprocity inside first-party catalogs (fragment-to-base edges may be one-way since a base cannot name persona types), and the anti-restatement rule (no intent equals the type name; no `why` is only the target's name). The authoring law for review: intents name the JOB in the user's words; `why` names the discriminating AXIS (count, persistence, data shape, interaction), never the recipe, which stays in mini-skills (`variant-picker.md` already teaches the <=3 rule; the ADR-0091 §4 double-injection lesson applies). The byte cost is bounded by a measured `SELECTION_GUIDANCE_CHAR_BUDGET` enforced in `prompt-drift.test.ts` (the `DOGFOOD_INVENTORY_CHAR_BUDGET` discipline, never truncation); the composed default prompt moves in all four pinned keys and is recaptured deliberately with `recapture-baseline.test.ts`. The change is a contract fork (inventory line format, a new byte-pinned asset class, a new coverage law) and earns a PROPOSED ADR, never self-ratified. The descriptor schema, `ComponentDef`, `loadCatalog`, `composeCatalog`, and the catalog SPEC §5.1 are untouched.

Decomposition: `.sdlc/work/catalog-notfor-intents/decompose/manifest-v1.json` (technical-architecture, plan mode, coverage_check clean, quadrant load-bearing); report at `.sdlc/work/catalog-notfor-intents/decompose/report.md`.

## Rejected alternatives

- `intents`/`notFor` as `ComponentDef` fields in `catalog.json`: ships prompt-only prose into every browser renderer bundle, reds the zero-headroom app marginal budget whose exception is marked final (`measure-size.mjs:686-700`), widens the render contract (`loadCatalog`, `composeCatalog`, SPEC §5.1) for data the renderer never reads, and contradicts the ADR-0097 / `feed-catalog.ts` precedent of per-type policy living beside the agent.
- Descriptor frontmatter (`controls/*/*.md`) as the home: `notFor` edges name catalog type ids inside one type set; `a2ui-basic` and persona types have no descriptor; `components` would learn a2ui vocabulary against the inward-only DAG; ADR-0173 cl.5 keeps catalog content out of descriptor generation.
- A separate `confusableWith` field: redundant with reciprocal `notFor` edges; two fields invite drift.
- A `## Choosing between components` pairs section instead of per-line clauses: loses locality next to the props the model is reading; kept as the named fallback if the measured delta blows the ceiling.
- Hand-listed CONFUSABLE_GROUPS table in the gate: an allowlist by another name; the bijection + reciprocity rules give the gate teeth without one.
- Exempting sub-types (Option, Tab, CardHeader, ...) from `intents`: an exemption marker is allowlist drift; "one choice inside a Select" is a cheap, honest intent.
- Deriving the site choosing guide from the sidecar: the sidecar is Node-only and the page runs in the browser; cite instead, and leave a browser-safe projection as a follow-up.

## Risks

- The measured guidance delta exceeds the design ceiling and forces the section-render fallback or a cut in caps; the number is set from the authored default sidecar, not guessed.
- Reciprocity forces weak reverse `why`s on a few asymmetric pairs; the review rubric (D7) must reject filler rather than let the gate's green stand in for quality.
- The genui dogfood inventory (`dogfood-inventory.ts`, descriptor-derived) carries no guidance; an owned limit of this wave, not a gap to patch here.
- The sidecar authoring is 97 entries of judgment; a `why` that restates a mini-skill sentence re-creates the ADR-0091 §4 double-injection defect.
- In-page tooling (`scripts/eval-a2ui-catalog.mjs`, the site) cannot read the sidecar; only Node evals via `./agent` can.
- If the loader throws on an unresolvable edge at module load, a half-authored sidecar breaks every prompt test until fixed; acceptable because the bijection gate is the standing guard, but builders must author type by type against the gate.
