## Task goal
A chat turn picks its response type deliberately: plain text, an A2UI surface, or text then a surface, with text streaming first so the chat feels fast. Decided inside the turn by the model through a `render_surface` tool (text is the default), not by a router model call in front of it.

- Steering fields (SPEC RTS-R6 and R7 after step 1; evidence under Assumptions): `ProduceOptions.responsePreference?: ResponsePreference` is the mechanical user override from the request (the future composer toggle; `'auto'` means none); `ProduceOptions.prefers?: ResponsePreference` is the persona hint, advisory only: it never changes the tool offer or `toolChoice` (step 5 composes it into the prompt; this step only declares the option). Effective override = `detectUserOverride(input)` (the intent's own words win as the latest instruction), else `opts.responsePreference` when not `'auto'`. Text override: `render_surface` is not offered. Surface override: `toolChoice: { name: 'render_surface' }`; a round that returns no payload spends one correction round coded `SURFACE_REQUESTED` with a one-sentence hint, then ships the text with `SURFACE_REQUESTED_UNMET` on the trace.
- Tool offer: `[...opts.tools, renderSurfaceTool(sessionKnownSurfaceIds(session))]`, `terminalTools: ['render_surface']`, unless `a2uiEnabled === false` (request byte-identical to today) or a text override. On a turn that offers the tool, `produce()` always supplies an executor that captures a `render_surface` input (`jsonl`, `target`), returns `received`, and delegates every other name to `opts.executeTool`. On a turn that does not offer it (text override, `a2uiEnabled === false`), no capture wrapper is installed: the request carries `opts.executeTool` unchanged (absent when the caller gave none), so a `render_surface` call reaching an executor on such a turn is never captured and never ships a surface. The `user override` describe proves this with a stub that calls `render_surface` anyway on a text-override turn and asserts no A2UI line ships, and with the same stub on a turn with no override phrase asserts the surface does ship (the negative control); step 8's override turn and kit scenario depend on it.
- Round classification: a captured `render_surface` payload makes the round a tool round and the payload wins; A2UI or genui lines found in that round's text channel are dropped from the reply and tallied as `TEXT_JSONL_IGNORED` on the trace (SPEC RTS-R3 after step 1). Else `isLegacyShape(text)` runs today's path byte for byte (RTS-R4). Else the trimmed text after an optional peeled meta-line is the reply and becomes the outgoing meta-line `note` (the model-authored `note` when the text is empty).
- The payload runs through today's chain in today's order and codes (assemble, stamp, `validateA2ui` with seeds and `atFinalize`, FEED_SCOPE, semantic checks, NET_NOOP, ask integrity). A failure is a self-correct round whose feedback names the tool ("Call render_surface again with the COMPLETE corrected JSONL; keep your reply text addressed to the user"). At the bound with non-empty text: ship the meta-line with `note`, `rounds`, the last codes plus `SURFACE_DEGRADED`, and no content line; empty text: `ProduceHalt` as today.
- `textDelta`: `meta-line.ts` gains `textDelta?: string` on the envelope and `readMetaLine` (shallow: a non-string drops only that arm). `produce()` yields `{"a2uiMeta":{"textDelta":"<fragment>"}}` per fragment only when no integration tool is declared and the text is not the legacy shape (fragments held until the first newline or until the first non-whitespace character is known not to be `{`); the final meta-line still carries the whole `note`; A2UI lines never precede validation. Consumers checked: every site and devtools `readMetaLine` caller assigns `note` only when defined (`git grep -n "readMetaLine"`), so a delta-only meta line leaves them unchanged.
- `onRepairRound?(ctx: { round; failures }) => { effort?; model? } | undefined` consulted at the top of each self-correct round (RTS-R9); absent is byte-identical.
- `session.ts`: `appendAssistantTurn(session, jsonl, note?)`: when `note` is a string whose trim is non-empty, store the note alone if `jsonl` is empty, else `<note>\n<jsonl>`; an absent or blank note stores `jsonl` alone, byte-identical to today (so a note-only turn never carries a trailing newline).
