T-0199 step 1 (the compare half; built in its own ticket). Each tile is an A2UI canvas at data-tier="widget" data-scale="md" inside the 400px chat column, drawn light and dark. A listbox: each option is one role="option" target with no Button inside it. The best option carries a "Best" text pill plus a ring, the picked one a "Your pick" pill plus a fill, never color alone. Static drawing.
