## Task goal
A chat turn picks its response type deliberately: plain text, an A2UI surface, or text then a surface, with text streaming first so the chat feels fast. Decided inside the turn by the model through a `render_surface` tool (text is the default), not by a router model call in front of it.

## Step 2: The pure response-type module
level: L2
### Read first
- `packages/agent-ui/a2ui/AGENTS.md`
### Do
Create `packages/agent-ui/a2ui/src/agent/response-type.ts` and `response-type.test.ts` beside it (SPEC RTS-R1, R6, LLD section 2). Zero value imports: at most `import type` from `./agent-transport.ts` (`ToolDef`, `TurnInput`). Write every import statement in `response-type.ts` on one line (for example `import type { ToolDef, TurnInput } from './agent-transport.ts'`): the import-purity criterion reads `^import .*$` line by line, so a multi-line `import type {` block reds it even when the import itself is correct. Depends on: none.

Settled interface: `RESPONSE_TYPES = ['text', 'surface', 'both'] as const` and `ResponseType`; `RESPONSE_PREFERENCES = ['text', 'surface', 'auto'] as const` and `ResponsePreference` (step 6's validator reuses the const); `RENDER_SURFACE_TOOL_NAME = 'render_surface'`; `renderSurfaceTool(openSurfaceIds: readonly string[]): ToolDef` with `input_schema` `{ type: 'object', properties: { jsonl: { type: 'string' }, target: { type: 'string' } }, required: ['jsonl'] }`, a description that tells the model to call it only when the UI changes, names every open surface id, and asks for an update over a create when one fits; serialized under 1500 chars. `detectUserOverride(input: TurnInput): 'text' | 'surface' | undefined`: `undefined` unless `input.kind === 'intent'`; case-insensitive whole-phrase match of the SPEC RTS-R6 lexicons (text: "just tell me", "in words", "no card", "text only", "don't show", "skip the ui"; surface: "show me", "as a card", "as a table", "as a chart", "build a", "make me a", "render" as a whole word); when both match, text wins (text is the default, PRD-G2). `classifyResponse(hasText, hasSurface): ResponseType`. `isLegacyShape(text): boolean`: skip one leading line that parses as an object with an `a2uiMeta` key, then true when the next non-empty line parses as an object with a string `version` key or a `genui` key (genui lines ride the text channel today and are peeled by `produce()`, so they stay on the legacy path), else false. The test file covers every rule above, including `undefined` for "book a table for two" and for a `kind: 'client'` input.

Validation scope: the new test file, the a2ui `layering.test.ts`. Run `npx tsc -p tsconfig.json` before reporting; the whole `check` gate is step 9's.
