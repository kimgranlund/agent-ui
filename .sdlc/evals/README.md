# Evals

Generated by `scripts/e2e-admin/probe/run-capped.ts` (T-0241) whenever a round archives, or by `run-capped.ts --index .sdlc/evals`; do not edit by hand.

- `rounds/<YYYY-MM-DD>-<slug>/`: one live test round each. Its `README.md` is the entry file: every file present, where it came from and how to read it. Screenshots are never written here (T-0256): they go to the local evidence cache (`$AGENT_UI_EVIDENCE_DIR`, else `~/Library/Caches/agent-ui/evidence`, `<round>/<run>/turn-<n>.png`) and each `report.json` names them by absolute path; JSON, traces and ledgers are committed.
- `fog-manifest.json`: the context-fog-of-war mapping manifest; rounds archived from T-0259 on ingest with it as a session bundle, one conversation per probe run keyed on `runId` (`engineer.py ingest <round> --mapping fog-manifest.json`, T-0248, T-0259). `fog-manifest-v1.json` is the catalog-keyed mapping the three earlier rounds (no `runId` on their trace lines) were ingested with.
- `fog/<round>.json`: one record per ingested round, its published report id and mapping hash; the round README shows it.
