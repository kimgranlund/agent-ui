# Layout

Any other folder directly under `docs/` is a topic. It holds the designs, specifications, and decisions for one concept.

## Homes

- `maintenance/`
- `reference/`
- `reports/`

## Frozen paths

- `docs/reports/`
- `.claude/docs/adr/`

The ADR system is retired (Kim, 2026-10-14, T-0164). Existing ADRs stay citable; nothing is added or changed. A decision lives in the ticket that makes it and, as a standing rule, in the owning reference doc or skill, so `decisions/` is not used here.
